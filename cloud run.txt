流程:
    Python 程式
        ↓
    requirements.txt：列出 Python 套件
        ↓
    Dockerfile：寫出執行環境怎麼安裝
        ↓
    gcloud builds submit：把它打包成 image
        ↓
    Artifact Registry：存放 image
        ↓
    Cloud Run Job：用這個 image 跑爬蟲

目前最簡單先改善的方式是 deploy 時把等待時間加長：

PAGE_SLEEP_SECONDS=8

也就是正式指令改成這樣：

--set-env-vars="GCS_BUCKET=tibame-bronze,GCS_PREFIX=raw_data/direct_transaction/test_da,YEARS_TO_CRAWL=2026,MAX_PAGES_PER_YEAR=0,SAVE_EVERY_PAGES=10,PAGE_SLEEP_SECONDS=8,LOCAL_WORKDIR=/tmp"

原本預設是：

PAGE_SLEEP_SECONDS=5

Cloud Run 上我會建議先改成：

PAGE_SLEEP_SECONDS=8

如果還是很多失敗，再改：

PAGE_SLEEP_SECONDS=10




================================================================================================

| 環境變數                   | 用途                        | 沒設定時                                                                   |
| ---------------------- | ------------------------- | ---------------------------------------------------------------------- |
| `GCS_BUCKET`           | 指定要上傳/下載的 GCS bucket      | 通常預設 `tibame-bronze`                                                   |
| `GCS_PREFIX`           | 指定 bucket 裡面的資料夾路徑        | 例如 `raw_data/direct_transaction` 或 `raw_data/t_rec/direct_transaction` |
| `PAGE_SLEEP_SECONDS`   | 換頁或重抓頁面後，要等幾秒讓網頁資料載入      | 例如 `5` 或 `8`                                                           |
| `DETAIL_SLEEP_SECONDS` | 點「詳情」後，等待 modal 詳情視窗打開的秒數 | 通常 `1`～`2`                                                             |
| `RESTART_EVERY_PAGES`  | 跑幾頁後重開瀏覽器，避免 Chrome 卡住    | 例如 `50` 或 `100`                                                        |
